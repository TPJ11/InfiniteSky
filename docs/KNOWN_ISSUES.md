# Known Issues and Release Blockers

These issues are based on the source audit, migration matrix, and executed test evidence. Severity reflects release impact, not an exploitability claim beyond the cited preconditions.

| ID | Description | Affected subsystem | Severity | Reproduction / evidence | Impact | Workaround | Release impact | Status |
|---|---|---|---|---|---|---|---|---|
| K-001 | Full client character selection and world-entry packet flow is absent | Protocol, networking, player lifecycle | Critical | World listeners have no gameplay dispatch; see `NET-008..009`, `PRO-008..019`, `ENT-020..021` | Client cannot complete the login-to-world journey | None for original client | Blocks playable release | `BLOCKED` |
| K-002 | Most gameplay handlers are absent, dormant, partial or source-stubbed | Gameplay | Critical | See `GP-001..038`, gameplay audit reports | No source-verified MMORPG gameplay journey | None | Blocks migration acceptance | `BLOCKED` |
| K-003 | Legacy login credentials use unencrypted TCP when exposed | Authentication/network | High | Confirmed by raw `NetworkStream` path and source login packet | Passive observation can expose credentials | Keep listeners disabled/loopback or use approved trusted tunnel | Blocks public deployment | `BLOCKED` |
| K-004 | Legacy account passwords are plaintext in stored documents | Authentication/persistence | High | `db/account.js` and active login source; see `SEC-002` | Database/backup disclosure exposes reusable credentials | Restrict DB/backup access; coordinated credential migration required | Blocks production data use | `BLOCKED` |
| K-005 | Mongo TLS is not required by application validation | Persistence/deployment | Medium | Validator accepts remote MongoDB URI schemes; deployment URI not inspected | Conditional exposure of DB traffic | Require validated TLS or protected database network operationally | Deployment-specific blocker | `IN_PROGRESS` |
| K-006 | MongoDB compatibility is not established against a real deployment | Persistence | High | Two opt-in container tests skipped; BSON fixtures synthetic | Collection, index, types, and unknown fields may differ | Verify against isolated sanitized copy | Blocks data acceptance | `BLOCKED` |
| K-007 | Original game data and region corpus are incomplete | GameData/zones | High | No `.IMG` or `.WREGION` files present in repository | Full catalog, terrain, portal and gameplay behavior unavailable | Supply authorized server data with inventory/hashes | Blocks world/gameplay parity | `BLOCKED` |
| K-008 | Original client build/version is unavailable | Compatibility | High | No client executable/build or client-attributable test environment | No real-client claim possible | Provide authorized test build and isolated environment | Blocks compatibility acceptance | `BLOCKED` |
| K-009 | World listener has no gameplay packet handlers | Networking/protocol | Critical | `AuthenticationIncomingPacketSink` is the only production sink | World TCP acceptance is not game readiness | Keep network disabled except isolated tests | Blocks public/playable release | `BLOCKED` |
| K-010 | Scripting/plugins and GM/admin commands are not implemented | Runtime/admin | High | No compatible .NET runtime or command dispatcher; documented in matrix | Legacy automation and administrative features unavailable | Do not rely on legacy script/CLI paths in .NET | Blocks feature parity if required | `BLOCKED` |
| K-011 | Performance results cover login only and are bounded to 100 sessions | Performance | High for capacity claims | Prompt 23 harness; zero active players tested | No gameplay capacity, long-soak or overload guarantees | Make no player-capacity claim | Blocks capacity claims | `IN_PROGRESS` |
| K-012 | Readiness health checks are registered but no HTTP health endpoint exists | Operations | Medium | No HTTP health host/route in server project | External orchestrator cannot query a built-in endpoint | Use process/log monitoring; do not infer readiness from process existence | Deployment limitation | `IMPLEMENTED` |
| K-013 | `ResetActiveAccountsOnStartup` defaults true and updates all account active flags | Persistence/operations | High for shared DB | Mongo host startup behavior; multi-instance tests absent | Can affect other instances sharing the collection | Single process only, or explicitly disable after stale-flag policy review | Multi-instance deployment blocked | `IN_PROGRESS` |
| K-014 | Current tests do not establish end-to-end gameplay, live DB recovery, or original-client compatibility | Verification | Critical | 188 passes with 2 Mongo tests skipped; no client available | Migration cannot be accepted from current tests | Complete prerequisite evidence and tests | Blocks migration acceptance | `BLOCKED` |
