## Known compatibility differences

- The .NET authentication session store enforces one in-process account session; the legacy login handler checks a live world socket and has a `Level > 80` stale-active exception. The account-level value is now available, but this duplicate policy is not changed.
- Missing/null account `Level` maps to the legacy schema default 0. Malformed or non-finite values now fail closed as malformed authentication data; this is a narrow safety correction for invalid stored BSON.
- Login/world transfer remains name/session based only in the legacy implementation and is not represented as fully secured/compatible in C#.
- Unsupported client statuses, packet tails, gameplay formulas, scripts, and moderation behavior remain unimplemented rather than inferred.

Prompt 19 did not modify original Node.js source. No Prompt 20 implementation or integration campaign has started.
