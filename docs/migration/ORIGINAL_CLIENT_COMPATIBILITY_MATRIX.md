# Original Client Compatibility Matrix

## Status semantics

This matrix concerns compatibility with an actual original game client. `VERIFIED` requires client-based evidence and is deliberately unused here: no usable client executable/build was available in the repository or project workspace. Source-derived protocol fixtures and simulated loopback tests are described separately and do not establish original-client compatibility.

Client build for every row: **unknown / not available**. Original Node behavior refers to checked-in source, not a live reference-server run. The server commit at inventory time was `b283640`.

## Protocol-only evidence is not client compatibility

- The 21-byte login greeting is now encoded at login connection-open and asserted against the original Node-derived fixture.
- Existing login, frame, and primitive tests exercise simulated bytes, not a captured client transcript.
- The old repository pcap has no documented client build or provenance and is not used as a golden client fixture.
- No original client or live original Node server was run.
