# Scripting Compatibility Matrix

## Status and inventory rules

Statuses describe the .NET migration, not whether Node.js code exists. `NOT_APPLICABLE` means the root server has no such implementation to migrate. The source families below are grouped only where they share one loader and execution contract; each matching `.js` file is a separate module, not a separately declared plugin.

The root `main.js` is the authoritative runtime. `FruitSalad/` is a separate, experimental process tree and is not interchangeable with root behavior. Paths and line references below point to the tracked source.

## Feature-level migration status

| Matrix ID | Status | Concrete blocker / evidence |
|---|---|---|
| SCR-001 | BLOCKED | No .NET JavaScript runtime can reproduce the root shared Node context and host APIs without porting the dependent services; no runtime is selected or bundled. |
| SCR-002 | BLOCKED | Packet modules depend on source packet handlers and shared registries; those handlers have not been ported into C# protocol adapters. |
| SCR-003 | NOT_STARTED | FruitSalad RPC/child processes are an alternate experimental runtime, not root behavior; no .NET compatibility contract exists. |
| SCR-004 | BLOCKED | Root permits configured filenames but the checked-in config has no external entries and the plugin directory is absent; the scripts require root globals. |
| SCR-005 | BLOCKED | Bundled command modules call global `GMCommands`/`Command` and perform admin/gameplay operations; actual command migration is explicitly out of Prompt 17 scope. |
| SCR-006 | NOT_STARTED | Root join/leave hooks exist but the checked-in root zone script is not loaded; FruitSalad's Nangin script is a stub. |
| SCR-007 | NOT_APPLICABLE | Dropbox/GitHub/Drive are README references only; corresponding plugin source directories are absent. |
| SCR-008 | BLOCKED | The root `sandbox.js` returns `{}` and is not passed into the two-argument `PacketCollection` constructor; the VMScript path executes trusted code in the server process. |
| SCR-009 | NOT_STARTED | Root `main.events` is application lifecycle signaling, not an independently consumed C# script/plugin bus. |
| SCR-010 | NOT_STARTED | No active script scheduler was found; root `GameStep` is runtime infrastructure and FruitSalad's Nangin scheduler call is commented. |
| SCR-011 | BLOCKED | Shared globals and optional reload transfer are not a persistent script-state model; no source-backed script-state collection exists. |
| SCR-012 | BLOCKED | Legacy modules receive ambient mutable services/objects; the .NET host has no source-verified bounded script context to expose. |
| SCR-013 | BLOCKED | Legacy syntax/runtime errors are logged while discovery proceeds, and unload only removes loader bookkeeping; there is no reliable rollback, subscription cleanup or bounded execution contract to port. |

No script or plugin is marked `IMPLEMENTED` or `VERIFIED`. The .NET Scripting project contains only its project file/reference and no runtime source or tests. Exact future feature/API ownership remains gated on the dependencies listed above.
