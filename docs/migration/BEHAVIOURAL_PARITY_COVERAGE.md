# Prompt 22 Behavioural Parity Coverage

## Evidence policy

Evidence levels are independent of migration statuses. A feature is not Level A/B verified merely because a loopback socket or source-derived fixture passes.

| Level | Evidence |
|---|---|
| A | Original-client behavior actually compared with the .NET server. |
| B | Equivalent scenario actually executed against Node.js and .NET and compared. |
| C | Source-derived binary/BSON/data fixture with an exact asserted result. |
| D | Source-derived rule, mapping or state-transition test. |
| E | Implementation-only test with no independent original-behavior result. |

Available evidence in this repository is C/D/E. No Level A or B tests ran. The current matrix has 69 `IMPLEMENTED`, `IN_PROGRESS` or `VERIFIED` features; the groups below map all of them to the test evidence available and call out partial or absent verification.
